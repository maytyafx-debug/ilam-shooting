# پایگاه اطلاع‌رسانی هیئت تیراندازی استان ایلام

نسخه بازطراحی‌شده صفحه اصلی با تمرکز بر معرفی نهادی، اطلاع‌رسانی عمومی، شفافیت اداری و آرشیو اسناد عمومی.

- مخزن: https://github.com/maytyafx-debug/ilam-shooting
- شاخه انتشار فعلی: `main`
- شاخه بازطراحی: `feat/ilam-admin-portal-v1`
- فناوری: HTML، CSS و JavaScript ساده
- بدون نیاز به مرحله Build

## محدوده این نسخه

این نسخه یک پورتال عمومی و اداری است و شامل بخش‌های زیر می‌شود:

- معرفی هیئت و مأموریت اطلاع‌رسانی
- معرفی ساختار و مسئولیت‌های سازمانی در سطح عمومی
- محل انتشار اخبار و اطلاعیه‌های رسمی پس از تأیید
- آرشیو گزارش‌ها و اسناد عمومی
- بخش ارتباط اداری، تا زمان تأیید اطلاعات تماس

محتوای نمونه یا بخش‌های فاقد اطلاعات تأییدشده با عبارت «در انتظار تأیید» مشخص شده‌اند. هیچ نام، سمت، آمار، نشانی یا خبر واقعی بدون منبع رسمی به صفحه افزوده نشده است.

## فایل‌های تغییرکرده در این بازطراحی

- `index.html`: صفحه اصلی جدید و ناوبری بخش‌های عمومی
- `style.css`: هویت بصری جدید، طراحی واکنش‌گرا و پشتیبانی از کاهش حرکت
- `script.js`: منوی موبایل با کنترل‌های دسترس‌پذیری؛ بدون پردازش فرم یا ارسال داده

## محدوده خارج از این تغییر

صفحات قدیمی و مسیرهای مرتبط با ثبت‌نام، رویدادها یا ارسال فرم در این بازطراحی بهبود یا فعال‌سازی نشده‌اند و از ناوبری صفحه اصلی جدید نیز پیوند ندارند. فایل‌ها و داده‌های قدیمی عمداً حذف یا جابه‌جا نشده‌اند تا سابقه مخزن حفظ شود. پیش از هرگونه انتشار عمومی، مدیر مخزن باید درباره نگهداری یا کنارگذاری مسیرهای قدیمی تصمیم جداگانه بگیرد.

## پیش‌نمایش محلی

با Python 3:

```bash
python -m http.server 8080
```

سپس نشانی `http://localhost:8080` را باز کنید.

## انتشار

این پروژه فایل‌های استاتیک دارد. برای انتشار، شاخه موردنظر را در تنظیمات میزبان استاتیک انتخاب کنید. پیش از تغییر شاخه Production، نسخه پیش‌نمایش را در موبایل و دسکتاپ بررسی و محتوای نهایی را با مسئول رسمی تطبیق دهید.

## کنترل نهایی پیش از انتشار

- بررسی نمایش راست‌چین و فونت فارسی
- بررسی منوی موبایل و پیوندهای داخلی
- بررسی کنتراست، فوکوس صفحه‌کلید و اندازه متن
- جایگزینی متن‌های «در انتظار تأیید» فقط با داده رسمی
- بازبینی جداگانه صفحات قدیمی و تنظیمات سرویس‌های متصل
- اطمینان از عدم انتشار اطلاعات شخصی یا محرمانه
